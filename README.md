# Simple Go App for CI/CD Demo

This is a basic Go application to demonstrate CI/CD pipeline concepts.

## What it does
- Provides simple math functions (Add, Subtract)
- Includes unit tests
- Ready for containerization

## How to run locally
```bash
go run main.go
```

## How to test
```bash
go test -v
```

## Next Steps
This project will be used to build a complete CI/CD pipeline with:
1. **GitHub Actions** - Automated testing on every commit
2. **Docker** - Containerize the application
3. **Deployment** - Automatically deploy when tests pass
