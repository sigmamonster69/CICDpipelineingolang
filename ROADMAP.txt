CI/CD + DevSecOps learning roadmap

Goal:
Build a small Go project that looks and behaves like a real CI/CD pipeline so I can keep extending it later.

Step 1 - Understand the app
- Read cmd/cicd-demo/main.go
- Read internal/app/app.go
- Read internal/app/app_test.go
- Run the app locally when Go is installed

Step 2 - Understand CI
- Read .github/workflows/ci.yml
- Learn what checkout, setup-go, build, and test do
- Make sure the pipeline runs on pushes and pull requests

Step 3 - Add basic Dev tools
- Add go fmt
- Add go vet
- Add a Makefile with test, build, and lint commands

Step 4 - Add containers
- Create a Dockerfile
- Create docker-compose.yml
- Learn how the same app runs inside a container

Step 5 - Add security checks
- Add golangci-lint
- Add gosec
- Add Trivy for dependency and container scanning
- Add secret scanning with gitleaks or GitHub secret scanning

Step 6 - Add delivery flow
- Push images to a registry
- Add staging deployment
- Add production deployment later

Tools to install or learn
- Git
- Go
- Docker
- GitHub Actions
- Make
- golangci-lint
- gosec
- Trivy
- gitleaks

What to practice next
- add a new Go function
- add a test for it
- add a CI step for linting
- add a Docker build step
