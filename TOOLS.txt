CI/CD + DevSecOps tools to learn

Core tools
- Git
- Go
- Docker
- GitHub Actions
- Make

Helpful CI/CD tools
- golangci-lint
- go vet
- gofmt
- docker compose
- GHCR or Docker Hub

Security tools
- gosec
- Trivy
- gitleaks
- GitHub secret scanning

Typical install commands on Mac
- brew install go
- brew install docker
- brew install gh
- brew install golangci-lint
- brew install trivy
- brew install gitleaks

What each one does
- Git stores your code history
- Go builds and tests the app
- Docker packages the app
- GitHub Actions runs CI
- Make gives you short commands like make test
- golangci-lint checks code quality
- gosec checks Go security issues
- Trivy scans images and dependencies
- gitleaks checks for secrets in code
